Tenable's plugin metadata is the primary source; this step checks whether outside sources corroborate or sharpen it, scoped to the Tier 1/2 findings above. Sourced via web search, not fabricated — see footer for the underlying references.

WSUS RCE (win2016) — confirmed active intrusions, not just KEV-listed
Unit42 and Huntress independently observed real post-exploitation — shell spawned via the WSUS worker process, base64 payload decoded, environment enumerated, results exfiltrated to a webhook — within hours of Microsoft's Oct 23, 2025 emergency patch. Activity specifically targets WSUS exposed on its default ports 8530 (HTTP) / 8531 (HTTPS).
BlueKeep (dc1) — CISA flipped its ransomware-use flag to "known" in July 2025
Previously listed "unknown" since the CVE's 2019 disclosure. CISA updates this field silently, with no changelog entry — easy to miss on a familiar, years-old CVE. On a domain controller, ransomware-capable RCE is the worst-case outcome, not a hypothetical one.
Windows Server 2008 R2 (dc1) — zero vendor patch path since January 2024
Microsoft's own lifecycle page confirms mainstream support ended Jan 2015, extended support Jan 2020, and all four years of Extended Security Updates — including the Azure-only year — ended Jan 10, 2024. Tenable will keep surfacing "critical" findings here monthly; none of them have an official fix coming. Migration is the only real remediation, not a patch.

Critical kill chain
dc1 carries two independent, unauthenticated RCEs (Log4Shell, BlueKeep) — either alone gives Initial Access straight to SYSTEM on the domain controller. Separately, win2016's WSUS RCE is a trust-root compromise: every domain-joined host pulls "updates" from WSUS, so a confirmed intrusion there is a path to fleet-wide compromise, not just one box. These are independent chains converging on full domain compromise — fix dc1 first, then win2016.
